# 🎂 Dulce Día - Página de Cumpleaños

Una página web elegante y cálida para celebrar un cumpleaños especial. Diseñada con una paleta crema-rosa suave, animaciones delicadas y secciones interactivas.

## ✨ Características

- 🌸 **Diseño cálido**: Paleta crema, rosa pastel y dorado
- 📱 **100% responsive**: Se ve perfecto en móvil, tablet y desktop
- 🕯️ **Vela interactiva**: Sopla con el botón o con el micrófono
- 🎊 **Confeti animado**: Sorpresas al interactuar
- 💌 **Libro de deseos**: Los mensajes se guardan en el navegador
- 🖼️ **Galería de amigas**: Con efectos hover elegantes
- 📜 **Confesiones**: Cartas con diseño de tarjetas
- 🕐 **Timeline**: Recorrido por el día

## 🚀 Cómo usar

1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. Personaliza los textos, fotos y confesiones
4. ¡Listo para celebrar!

## 📸 Agregar fotos

Coloca tus fotos en la carpeta `assets/img/` con los nombres:
- `amiga1.jpg`
- `amiga2.jpg`
- ... hasta `amiga6.jpg`

Si no agregas fotos, se mostrarán placeholders automáticamente.

## 🎨 Personalización

Edita las variables CSS en `css/style.css`:

```css
:root {
    --cream: #FFF5E6;
    --pink-light: #FFE4E1;
    --pink: #FFB6C1;
    --pink-strong: #F8A5B8;
    --brown: #6B4423;
}
